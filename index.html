Sobre el autor

Una biblioteca
propia.

Axel Macedo es autor y creativo de Houston, Texas. Esta biblioteca nace para presentar sus libros como objetos que merecen ser descubiertos, leídos y compartidos.

Cada nuevo título puede convertirse en una sala propia dentro de esta colección: portada, sinopsis, extractos, ediciones, reseñas y un camino directo para conseguir el libro.
