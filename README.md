# Axel Macedo

Welcome to the personal website of **Axel Macedo**, an **Author, Graphic
Designer, and Painter based in Houston, Texas**.

This website is a personal creative portfolio designed to showcase
Axel's books, graphic design projects, paintings, and other creative
work.

![Axel Macedo](./images/axel-macedo.jpg)

## About

Axel Macedo is an author, graphic designer, and painter based in
Houston, Texas, with a passion for bringing ideas to life through
different forms of creative expression.

Writing provides a way to tell stories and explore ideas. Graphic design
provides a way to communicate visually. Painting provides a space for
artistic expression through color, form, emotion, and imagination.

The goal of this website is to bring these creative disciplines together
in one personal digital space.
